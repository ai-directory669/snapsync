## ✨ Features
- 📋 **Zero-Lag Clipboard Sync**: Copy on PC, paste instantly on Android (and vice versa).
- 🚀 **Drag & Drop File Drop**: Direct P2P transfer over local Wi-Fi with maximum speed.
- 🔒 **100% Private**: Runs completely offline on LAN. Zero data leaves your room.
- ⚡ **Zero-Config Discovery**: Auto-detect devices on the same Wi-Fi using mDNS.
- 🆓 **100% Free & Open Source**: No paywalls, no subscriptions.
